## BIGGERBOX 适合什么用途

如果当前确实有货，BIGGERBOX 的定位比较清楚：用较低年付价格换取一台基础配置、特定线路和固定机房的自管理 VPS。

比较适合的场景包括：

- 个人博客或小型展示站
- 低访问量 WordPress 网站
- 轻量级开发测试环境
- 个人 API、Webhook 或定时任务
- 需要海外 Linux VPS 的学习项目
- 对月流量有一定要求，但不需要大量 CPU 的服务

1GB 内存可以运行轻量网站和基础服务，但不适合把它当作高并发生产服务器。运行较重的数据库、多人协作应用、编译任务或多个容器时，内存和 CPU 都可能成为瓶颈。

搬瓦工官方服务属于 self-managed，也就是自管理 VPS。官方提供 KiwiVM 控制面板，可以完成开关机、重装系统、快照、反向 DNS、部分机房迁移和使用量查看等操作，但不会替用户配置网站、排查应用错误或恢复业务数据。

因此，BIGGERBOX 更适合愿意自己处理 Linux、SSH、防火墙和网站部署的人。它不是托管型主机，购买后不会有人替你安装 WordPress、配置 Nginx 或修复程序报错。

## 购买前必须检查的限制

### 1. BIGGERBOX 可能不在常规购物车中

官方当前公开页面没有直接列出 BIGGERBOX。通过普通入口看不到该型号时，不要自行修改 URL 参数，也不要把第三方文章中的 PID 直接拼进地址。

### 2. 线路名称不能代替实际测试

“CN2 GIA”是线路描述，不等于任何地区、任何时间段都能保持相同延迟和丢包率。实际体验还与本地运营商、晚高峰拥塞、目标网站位置有关。

### 3. CPU 不是完全独占

官方服务条款对不同限量方案设置了 CPU 使用限制。BIGGERBOX Plans 的长期平均 CPU 上限记录为 1 个核心的 25%；超过小时平均限制后，VPS 仍会运行，但可用 CPU 周期会被限制。

这意味着它更适合轻量、间歇型任务，不适合长时间满载编译、持续转码或高 CPU 计算。

### 4. 自管理服务需要自己维护

官方不会替你处理应用层问题。购买后至少需要自己完成：

- SSH 登录和密钥管理
- 系统更新
- 防火墙设置
- 网站和数据库部署
- 定期备份
- 日志与资源监控
- 服务异常后的恢复

官方页面列出了 KVM、KiwiVM、root 权限、快照、重装系统和多种 Linux 系统支持，但这些功能并不等于托管运维。

## 退款和付款前检查

搬瓦工官方条款显示，新订单在满足条件时可以申请退款，但需要同时满足多个限制，例如订单为 30 天内的新服务、账户状态正常、流量使用低于月配额的 10%，并且相关 IP 没有进入黑名单。退款后，服务、数据、快照和备份都会被删除。

因此，购买 BIGGERBOX 后不要立刻把唯一的网站、数据库或重要文件放上去。先确认：

1. IP 是否能正常使用。
2. 目标地区的连接质量是否符合需求。
3. 机房是否支持你需要的迁移方式。
4. 备份是否能独立恢复。
5. 应用是否在 1GB 内存和 CPU 限制下稳定运行。
